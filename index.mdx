Firma is not a company with an org chart. It is an **Order** — a covenant collective
holding many fields of stewardship, in the sense the Order of Melchizedek is an order.
What it is building is one simple thing to state and a hard thing to do: a new operating
system for humanity. Not only the software — the formation of people, governance, purpose,
prosperity, community, and economics.

## One Order, five Domains

These are not five separate Orders. They are five Domains within the one Firma Order, each
with a distinct mandate, leadership and budget, all aligned to one purpose.

| Domain | What it does |
|---|---|
| **Firma Foundation** | Governs and protects the Order — covenant, constitution, standards, alignment. |
| **Firma Capital** | Stewards the resources — land, treasury, funds, real assets. |
| **Firma Labs** | Builds the systems — engineering, infrastructure, the products in flight. |
| **Firma Theosis** | Forms the people — formation, ministry, mission. |
| **Firma Frontier** | Establishes it in living places — campuses, Settlemint formation, network states. |

**Foundation governs ✴ Capital stewards ✴ Labs builds ✴ Theosis forms ✴ Frontier establishes**

The shape runs **Domain → Sphere → Pod → Role**. Domains organize Firma's major fields.
Spheres hold enduring missions. Pods preserve continuing capabilities. Roles define what each
person or agent owns.

Two lines carry how it is held: *The center holds shared purpose. The edges are trusted to
act.* And for governance: *Authority moves down. Accountability moves up.*

## How to read this handbook

Read **Who We Are** first. Everything else is downstream of it — the mission, the calling
beneath it, the values, the ethos we operate from, and the two floors we will not cross.

Then **The Code of Conduct**, which names those floors plainly, and **Firma Order and
Governance**, which explains how authority actually moves.

The rest is reference. Read it when you need it.

<Info>
  **On how real things are.** Firma marks its own certainty. **PROPOSED** is visible
  direction, **FORMING** is actively taking shape, **ACTIVE** is presently operating. Every
  number in Firma is a projection until a real deployment validates it — if you see a figure
  quoted as measured fact, that is a mistake worth reporting.
</Info>
